WEEK 6 REST API — QUICK START

1. Extract this folder.
2. Open a terminal inside the extracted folder.
3. Create/activate a virtual environment (see README.md).
4. Run: pip install -r requirements.txt
5. Copy .env.example to .env and change API_TOKEN.
6. Run: uvicorn app.main:app --reload
7. Open http://127.0.0.1:8000/docs
8. Run tests with: pytest

Read README.md for full setup, API usage, testing, GitHub and deployment instructions.
